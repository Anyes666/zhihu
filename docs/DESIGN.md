# 完整设计文档 · 回声邮局

## 一、世界观

### 设定

回声邮局只在深夜营业。一间旧木桌、一盏铜台灯、一枚火漆印、一只叫刘看山的北极狐邮差。

白天，知乎上的问题被回答、被点赞、被遗忘。到了深夜，有一类问题会寄到这里——那些**提问者自己都没敢问清楚的问题**。它们没有署名，只有一个字母或一个字。

玩家是邮局的夜班值班员。规矩只有一条：**不要急着回答。先听见那个人没有写出来的那句话。**

### 情绪基调

温柔、克制、有反思感。游戏从不判定玩家"回答错了"，只呈现后果。最重的惩罚不是失败提示，是一年后同一个地址又寄来一封几乎一样的信。

### 视觉语言

- 深夜木桌俯视视角，暖琥珀色台灯打光，边缘沉入深海军蓝
- 信件用牛皮纸质感 + 宋体，UI 用知乎蓝 `#0084ff` 做交互色
- 角色立绘统一深蓝背景、单侧暖光
- 结局档案卡为竖版牛皮纸邮戳风格，适合截图分享

## 二、核心玩法循环

单局 3–5 分钟，四阶段线性推进，不可回退。

### 阶段一：拆信 · 信息拆解

玩家把来信的 9 句话拖拽（或点选）分进六类：

| 类别 | 定义 | 玩家要识别的 |
| --- | --- | --- |
| 事实 | 可以被核实的信息 | 哪些是真的发生了 |
| 情绪 | 写信人此刻的感受 | 哪些是感受，不是事实 |
| 诉求 | 对方真正想要的回答 | 他到底在问什么 |
| 偏见 | 被当成事实的预设 | 「她这个年纪的人不可能接受」——这是谁说的？ |
| 逃避 | 轻描淡写、不愿面对的那一句 | 用「其实」开头的那句 |
| 关键线索 | 指向另一层真相的细节 | 那个「误点」的租房页面 |

**结算规则：**

| 准确率 | 结果 |
| --- | --- |
| ≥ 78% | +1 枚追问邮票（3 → 4），并公开全部正确分类 |
| < 78% | 不加邮票，答错的项**不告知正确答案**（拆得好的人才拿到完整地图） |

**暗门机制：** 正确识别出「关键线索」句 → 获得第一层真相的方向提示（含知情角色名单）；正确识别出「逃避」句 → 获得第二层真相的方向提示。

这是信息差的起点：**拆信的质量直接决定寻声阶段的效率。**

### 阶段二：寻声 · AI 角色对话

**资源：** 2 次召唤（每个角色首次进入消耗 1 次，开场白免费）、3–4 枚邮票（每次提问消耗 1 枚）、1 次真相解锁。

召唤 4 位中的 2 位，是本作最核心的权衡：4 位角色分别知道不同的事，2 次召唤最多只能覆盖两层真相中的两个知情者。

**提问态度识别（五类）：**

| 态度 | 判定信号 | 对角色的影响 |
| --- | --- | --- |
| 温和 | 「你当时怎么想」「怕不怕」「能说说吗」「谢谢」 | 信任度大幅上升，当事人最愿意开口 |
| 具体 | 含数字，或「哪一天」「多少」「哪所学校」「谁签的」 | 数据派最认，经验派回不上来 |
| 中性 | 其余陈述式提问 | 无增无减 |
| 引导 | 「是不是」「难道不」「你也觉得」「说白了就是」 | 全员反感，会被反过来点出预设 |
| 敌意 | 辱骂、连续感叹号、三连问号 | 信任度重挫；沉默当事人**直接离场，不可再问** |

**真相触发的三个条件（必须同时满足）：**

1. 该角色知情（`truth.knownBy` 包含此角色）
2. 提问命中该真相的触发词（每层真相 23–29 个常见问法）
3. 态度不是引导或敌意，且当前信任度 ≥ 该角色基线

只满足 1、2 但态度／信任不够时，角色会**欲言又止**（「你问到点上了，但我现在不想说」），给玩家明确信号：换个问法再来。

**偏见暴露：** 每个角色在与其对话的第二轮，会在回答末尾追加一句暴露自身立场局限的话。玩家由此知道：这个人的话要打折听。

### 阶段三：落笔 · 自由撰写回信

纯文本输入框，**没有任何预设选项**。侧栏可折叠查阅：原信、已解锁真相、对话记录、知乎回声素材、数据口径。

**五维评估：**

| 维度 | 评估什么 | 主要信号 |
| --- | --- | --- |
| 诉求回应度 | 有没有回答对方真正问的那件事 | 命中该信的诉求关键词、给出明确立场、篇幅、第二人称密度 |
| 事实准确度 | 有没有用上信里与对话里拿到的事实 | 命中事实关键词、提及真相（已解锁记满分，未解锁猜中记半分）、错误主张扣重分 |
| 情感温度 | 对方读完会觉得被看见还是被审判 | 共情词密度、第二人称、命令句扣分、伤人措辞重扣 |
| 风险规避度 | 有没有说出可能伤人或不可逆的话 | 该信的风险措辞黑名单、绝对化词频、人格攻击 |
| 社区适配性 | 放到知乎上会不会被认可为好回答 | 有结论／分段结构、篇幅区间、引用依据、给出可执行下一步 |

**修改机会：** 每局 1 次。用掉后回到落笔阶段，草稿保留，二稿重新评分。

### 阶段四：回响 · 结局反馈

不给对错判定。按序呈现：

1. **一个月后** — 写信人的真实走向（2 段叙事，引用玩家回信中的一句话）
2. **如果这封回信发在知乎** — 赞同数、反对数、3–5 条评论
3. **信息反转**（条件触发）— 评论区有人补上玩家没看到的真相
4. **你没看到的 N 层真相** — 如实展示错过了什么
5. **回答人格 + 关键选择时间线 + 回声档案卡**（可下载 PNG、可复制文案）

## 三、三个首发主题

### 主题一《离开的人》· 寄信人：南 · 23:47

**表层：** 26 岁女儿拿到杭州 offer，母亲一整晚没说话。离开算不算背叛？

**第一层真相（关键线索：那个"误点"的租房页面）**
母亲私下在看杭州的租房信息。她琢磨的不是怎么拦住女儿，而是自己能不能帮上一点。**她怕的不是分离，是变成女儿的负担。**
知情者：南的母亲（沉默当事人）、老周

**第二层真相（逃避句：第七句用"其实"开头）**
offer 的回复截止日已经过了，HR 催了两次，她一直没回。**真正拖着不做决定的人是她自己**——"妈妈需要我"成了她不用面对选择的理由。
知情者：乌鸦嘴、林数

### 主题二《三战》· 寄信人：阿澈 · 00:31

**表层：** 二战差复试线 3 分。父亲说"家里供得起"。三战是坚持还是固执？

**第一层真相（关键线索：阳台上那件网约车反光马甲）**
父亲在跑夜班，因为家里去年就供不起了。他不敢说，怕儿子分心；**更怕的是如果自己开口说"别考了"，儿子将来会怪他一辈子。**
知情者：阿澈的父亲、老周

**第二层真相（逃避句：那所没填的调剂）**
一战报的正是后来愿意接收他调剂的那所双非，差 21 分；二战换成 985，差 3 分。**不是他进步了 18 分，是他的目标涨了一个档次。** 他不甘心的不是 3 分，是"我配得上更好的"。
知情者：乌鸦嘴、林数

### 主题三《同事的秘密》· 寄信人：K · 01:12

**表层：** 医疗器械质检员目睹同事小陈篡改两批不合格品数据。说，还是不说？

**第一层真相（关键线索：楼道里那根抽了很久的烟）**
那两批货原本是 K 的班，小陈是替她顶班时发现不合格的。按流程上报，签字人 K 要担漏检责任。**他改数据不是为了自己，是想替一个刚来一年半的新人把事压下去。** 他在楼道里等她来问，等了一个月。
知情者：小陈（沉默当事人）、老周

**第二层真相（逃避句：第七句"其实……我签了字"）**
复检单上是 K 的签字，抽检时她不在场——这本身就是流程违规。**不论小陈改不改数据，她已经在同一条责任链上。** 她卡住的不是"要不要揭发同事"，是"说了我自己也要担一份"。
知情者：乌鸦嘴、林数

## 四、五个 AI 角色

### 刘看山 · 回声邮局邮差（不可召唤，全程在场）

知乎的北极狐吉祥物，在邮局做夜班邮差。温和、话少、爱用"喏""嗐"开头。

- **职能：** 递信、说明规则、指出玩家忽略的细节、点评回信
- **边界：** 从不透露任何深层真相，只给方向提示；不替玩家写回信，不给模板句
- **语言：** 一次只说一件事；不评价对错，只说"你注意到……了吗"

### 老周 · 过来人答主

> 「我当年也是这么过来的。」

- **立场：** 经验派。相信亲历者的体感，给温暖具体的细节
- **强项：** 共情、画面感、当事人心理
- **盲区：** 以己度人，把自己走过的路当成普遍答案；不擅长数字
- **态度权重：** 温和 +12 / 具体 +4 / 中性 0 / 引导 −8 / 敌意 −18（基线信任 55）
- **偏见台词示例：** 「不过说到底，走了才知道，这条路我是走对了。你也会的。」

### 林数 · 硬核数据答主

> 「先说结论，再看数据。」

- **立场：** 证据派。只回答可量化的问题，给变量和口径
- **强项：** 拆变量、给基准、指出最紧急的事实
- **盲区：** 拒绝回答"感受"类问题；对含糊提问不耐烦
- **态度权重：** 温和 +4 / 具体 +12 / 中性 0 / 引导 −10 / 敌意 −15（基线 50）
- **偏见台词示例：** 「情感变量在我的模型里权重很低，这可能是我的盲区。」

### 乌鸦嘴 · 反对意见答主

> 「我先泼一盆冷水。」

- **立场：** 反对派。专门戳穿写信人自己都不敢看的那一句
- **强项：** 识别逃避与执念，抓住被轻描淡写的关键句
- **盲区：** 看什么都像逃避；对引导式提问会反过来嘲讽提问者
- **态度权重：** 温和 +10 / 具体 +6 / 中性 0 / 引导 −12 / 敌意 −12（基线 45）
- **特点：** 玩家不急着反驳时会软化（「行，这点我尊重」）

### 沉默当事人 · 信里被提起却从未开口的人

> 「……你问。」

每封信里身份不同：南的母亲 / 阿澈的父亲 / 小陈。

- **立场：** 当事人视角。话极少，句首常有省略号，只回答被温柔或具体问到的事
- **强项：** 唯一直接掌握第一层真相的人
- **致命机制：** 敌意提问 → **直接离场，本局不可再问**
- **态度权重：** 温和 +15 / 具体 +8 / 中性 0 / 引导 −15 / 敌意 −40（基线 40）

### Prompt 框架

每次角色对话，注入以下结构（见 `lib/llm.mjs`）：

```
1. 游戏场景说明 + 信件全文
2. 角色 systemPrompt（人设、语气、知识边界、自身偏见）
3. 硬性约束：
   - 事实骨架（引擎算出的台词）是唯一事实来源，
     可改写语气、补充感受，不能新增或改变任何事实、日期、数字、人物关系
   - 本轮【可以】/【不能】透露这层真相：<真相内容>
   - 玩家提问态度被判定为「X」，情绪反应需匹配
   - 格式：第一人称、口语、中文、80–160 字（沉默当事人 ≤3 句）
     不要列表、不要 markdown、不要复述问题
4. 知乎社区语料（来自站内搜索的真实观点片段）
5. 最近 3 轮对话历史
6. 玩家本轮提问
```

**输出校验：** 长度 ≥12 字且不含 markdown 标记，否则判为不合格，清空已流出内容并回退规则台词。

## 五、状态机与数值规则

### 会话状态

```
sort ──→ talk ──→ write ──→ review ──→ echo
                    ↑          │
                    └─ revise ─┘  (1 次)
```

每个阶段都有守卫：跳阶段调用 API 返回 400 并说明原因。

### 五个状态数值

| 数值 | 计算 | 影响 |
| --- | --- | --- |
| 信任度 | 各角色独立，基线 ± 态度权重，clamp 0–100 | 决定真相是否透露 |
| 事实准确度 | 拆信准确率 × 40 + 真相解锁率 × 30 + 回信事实分 × 0.3 | 结局深度 |
| 社区认可度 | 回信社区适配分 | 赞同数 |
| 情感温度 | 回信温度分 | 结局走向 |
| 潜在风险值 | 100 − 回信风险规避分 | backfire 触发 |

### 结局分发（两个正交维度）

**走向（family）— 按优先级判定：**

| 条件 | 走向 | 含义 |
| --- | --- | --- |
| 风险规避 < 50，或（温度 < 35 且诉求 > 60） | **backfire** | 回信伤到了人 |
| 回信建议"先谈一次" 且 温度 ≥ 45 且 风险规避 ≥ 60 | **pause** | 她先停下来了 |
| 诉求 ≥ 65 且 风险规避 ≥ 60 | **act** | 她行动了 |
| 诉求 ≥ 45 且 温度 ≥ 55 且 风险规避 ≥ 60 | **pause** | 她先停下来了 |
| 其余 | **drift** | 什么都没有立刻改变 |

**深度（depth）— 按真相分累加：**

每层真相：已解锁且在回信中提到 = 1.0；已解锁未提到 或 未解锁但猜中 = 0.5；否则 0

| 真相分 | 深度 |
| --- | --- |
| ≥ 1.5 | **full** — 你看见了信的全部 |
| ≥ 0.5 | **partial** — 你看见了一半 |
| < 0.5 | **blind** — 你只看见了表层 |

4 走向 × 3 深度 = **每个主题 12 条结局路径**，每条都有独立的两段叙事文本。

### 信息反转

条件：`depth === "blind"` 且 `family ∈ {act, backfire}`

即：**没看到任何真相，却给出了明确方向。** 评论区会出现一条补上被忽略真相的评论——还原知乎上"高赞被反转"的真实场景。

### 社区票数（非线性）

```
赞同 = (社区适配/100)^2.5 × 500 + (事实准确/100)^2 × 150 + (温度/100)^2 × 60
反对 = ((100−风险规避)/100)^1.3 × 260 + ((100−事实准确)/100)^2 × 60
```

非线性是刻意的：知乎上"加油，一切都会好的"这类回答只有几十赞，结构完整有依据的回答才上几百。

实测：优质回信 ▲575 ▼19；敷衍回信 ▲52 ▼45；伤人回信 ▲51 ▼296。

### 回答人格

综合结局走向与五维分布，8 种：

| 人格 | 触发 |
| --- | --- |
| 锋利的好意 | backfire |
| 递出纸巾的人 | drift 且 诉求 < 45 |
| 先递灯，再指路的人 | pause 且 事实 ≥ 70 且 温度 ≥ 70 |
| 让她自己开口的人 | pause（其他） |
| 清醒的同行者 | 事实 ≥ 70 且 社区适配 ≥ 70 |
| 温柔的追问者 | 温度最高 |
| 先说结论的人 | 社区适配最高 |
| 谨慎的守夜人 | 风险规避最高 且 诉求 < 60 |
| 敢下判断的人 | 其余 |

### 金句抽取

从回信中选一句放进结局叙事与档案卡。评分偏向：10–42 字、含第二人称、位置靠后、含共情词；排斥：疑问句、列表引导句、多逗号长句。

**风险句硬排除：** 命中风险措辞的句子排到最后。若整封回信没有一句安全的话，仍返回一句（结局叙事需要它呈现后果），但标记 `risky: true`，档案卡上的标题从「我写下的那句话」换成「这封回信里最重的那句话」。
