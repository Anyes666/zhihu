# 原创体验升级 · 夜班门厅与平行试写

日期：2026-09-13。输入依据为五站真实浏览器体验，完整观察边界见 [COMPETITOR-REVIEW.md](COMPETITOR-REVIEW.md)。

## 产品定位

**不是替陌生人给出一个漂亮结论，而是在开口之前，学会听见回答的重量。**

“知乎内容 → 玩家辨析 → 原创来信互动 → 回信后果 → 同条件复盘”是本作的闭环。没有照搬竞品的投资模拟、修仙、图谱分支或卡牌机制。

## 已实现

### 1. 夜班门厅
- 用已有邮局书桌图、CSS 信封和邮戳组成独立的夜间场景；不再用大段说明填满首屏。
- 主按钮直接进入第一封信；保留三封信的自主选择。
- 首屏说明只保留动作、价值和时间预期，资源细则与知乎话题移到展开式说明。
- 三封信按困境展示；四个角色预览与匿名当事人的意象插画保持题材一致。
- 匿名席不再用年轻女孩头像代表不同来信中的母亲、父亲或同事；使用已有匿名背影意象，不表示真实外貌。

### 2. 互动引导
- 四步阶段条只解释进度，不是可跳过引擎守卫的导航。
- 每个角色提供两种开口灵感，基于本作来信的公开线索；点击只填入，必须再次确认发送，才消耗邮票。
- 切换角色清空旧问题；生成期间不能切入落笔；邮票用尽时禁用提问。
- 查阅知乎与进入落笔的按钮前置，侧栏只展示一条短参考，完整资料在参考台。
- 模型/规则来源按每次实际输出标注并随对话记录恢复，不把打字效果当作生成证明。

### 3. 参考台更贴近来信
- 知识来源卡按标题与来信主题的关键词排序，保留全部卡片，不改作者/来源/摘要。
- 明确“排序不代表适用于当事人”，不做心理诊断或虚构事实认证。
- 每封信两个检索角度示例，只填词、不自动发起查询。
- 已选来源笔记数量可见；仍保留最多两条、8–160 字的适用边界设计。

### 4. 草稿暂存
- 回信输入即时暂存于当前浏览器标签页的 `sessionStorage`，按会话 ID 隔离。
- 刷新可恢复；正式结局成功返回后清除此局草稿。
- 这是当前标签页暂存，不是账号云存档。关闭标签页、浏览器清理、服务端会话过期/重启后不能保证恢复。
- 存储不可用时显示提示，不声称已经保存。

### 5. 平行试写（本次核心新增玩法）

正式结局后，展开“如果那句话，换一种说法”：

1. 原稿填入另一张信纸，玩家自己修改，不提供一键高分答案。
2. 同一引擎在会话副本上重新计算，保持当时的线索、对话与资源背景，仅改变回信文本。
3. 并列展示原稿/试写的结局、句子及风险标记，可展开各自回响；展示五维差值。
4. 不改正式回信、资源、真相、来源笔记、时间线或档案卡；不额外调用知乎或模型，不生成可刷的模拟赞同数。
5. 仅在回响阶段开放，输入 10–2000 字；相同文本结果可重复。明确它是规则模拟，不是现实人生预测。

接口：`POST /api/session/:id/rehearsal`，请求 `{ "text": "另一版回信" }`。返回 `simulation:true`、`generated:false`、`original`、`alternate`、`delta`、`changed`、`boundary`。

## 没有声称完成的事

- 本轮浏览器使用 `LLM_PROVIDER=none`；模型路径的自动化依旧使用本地 mock。没有验证真实 DeepSeek 调用，不能把规则叙事当作 DeepSeek 输出。
- 未配置知乎 Access Secret，热榜与站内搜索继续验证明确标注的演示/无凭证降级；真实鉴权接口联合验收仍待本机安全配置凭据。
- 知识仅列表短摘要，不是全文阅读；语义真实性和提示注入安全仍不能靠提示词/格式检查完全保证。
- 没有付费生图、竞品资产移植、发布或部署；旧的长期运行服务没有被停止或替换。测试临时服务已退出。
- 未对评分做关键词作弊对抗的完整审计。本轮不改评分规则；试写旨在复盘，不宣称模拟结果代表现实伦理判断。

## 两分钟展示建议

1. 门厅一句话介绍：你不是在挑正确选项，而是在决定一个陌生人收到什么样的回应。
2. 用一个角色例句作为开头，自己修改后再发送。强调“例句不自动消费邮票”。
3. 展开知乎参考台，展示真实获取时间，标记一条“待核实”，说明“社区经验不是来信真相”。
4. 寄出一封认真回答，展示回执与结局。
5. 打开平行试写，改成武断的表达：观察同样线索下结局与安全维度改变；指出原档案没变。

亮点落脚：**AI 与平台内容帮助理解，玩家保留判断；既能玩，也能看见自己怎样回答。**
