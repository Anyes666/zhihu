# 首次值班：新手引导与个人回看

验收日期：2026-09-13。

## 玩家会看到什么

首次打开同一浏览器、同一站点时，邀请「今晚，我陪你值第一班」。可选开始引导或自己探索。引导中始终可以跳过；「收起」或 Escape 暂时隐藏提示，右下角可继续。完成或跳过后不主动重弹，也可以手动重开。

不是自动演示：玩家自己选信、分类、召唤、提问和回信。圈选外仍能操作，不锁定某个角色、真相路线或“正确答案”。引导不调用模型、不额外发起知乎请求，不改变评分、资源或结局。

| 环节 | 引导内容 | 何时推进 |
|---|---|---|
| 读信 | 先读原信，暂缓建议 | 玩家确认读完或自行进入拆信 |
| 拆信 | 先点句子，再选分类；圈住六类，显示已选句子 | 真实分类数量、选中状态与封存结果 |
| 寻声 | 任选角色，开场免费；提示只填入，发送才耗邮票 | 召唤成功、提问成功及服务端会话状态 |
| 倾听 | 看回应、语气与线索，而非只找标准答案 | 玩家确认看过，也允许继续自由问 |
| 知乎参考 | 查阅 → 辨析适用边界；明确来源，随时不查 | 真实展开参考台或选择略过 |
| 落笔 | 一件事实、一种感受、一个可做的小事 | 自由写作；可收起提示获得安静 |
| 评估 | 可改一次，也可看回响 | 已收到评分且操作绑定完成 |
| 回响 | 先看当事人后来怎样，再看模拟热度 | 结局流式完成后提示 |
| 回看 | 真正问过的问题、回信中的句子、拿到/遗漏的线索 | 玩家确认完成，可继续平行试写 |

## 情感设计的可验证边界

增加「刚拆信时，你也是这样想的吗？」回顾卡，位于叙事之后、平行试写之前：

- 展示本局最后一次真实提问及追问次数，不虚构倾听经历。
- 展示本局回信摘句。被引擎标记为风险措辞时，使用「需要重新掂量的那句话」，不当作金句赞美。
- 展示已解锁与未问到的真相标题。没有收齐，不等于玩家不在乎。
- 留一个可带到生活里的问题；不要求输入，不收集回答。
- 平行试写沿用原功能，可选，不强迫玩家写伤人回答或追求高分。

这些是让玩家反思的具体设计，不等于已经证明所有玩家都会感动。尚未开展真实新用户访谈或情感效果测评。只采用通用圈选/单步提示/动作推进交互，不复制其他游戏教程、文案或素材。本轮没有新增生成美术。

## 实现与存储

- `public/onboarding.js`：可测试的状态判断、个人回看模板、原生 DOM 圈选层。
- `public/onboarding.css`：桌面/手机布局、聚光、操作焦点、回顾卡。
- `public/app.js`：在页面事件绑定与操作成功后同步快照；替换页面时先挂起旧引导。
- `public/index.html`：引入样式。
- `server.mjs`：落笔响应增加已有维度元数据，支持刷新后恢复评分展示，不重新计算分数。
- `package.json`：新增语法检查与引导浏览器测试命令。
- `tests/onboarding.test.mjs`：首次/恢复/跳过状态、分支与风险回看测试。
- `scripts/browser-onboarding.mjs`：专门验证有引导路线。
- `scripts/browser-experience.mjs`、`scripts/browser-research.mjs`：通过真实点击「自己探索」检查旧玩法，而非偷偷关闭新功能。

引导仅将版本、active/skipped/complete 状态、已读节点和会话 ID 写入 `localStorage["echo.guide.v1"]`，不复制提问、回信或来源笔记。草稿仍使用原有本标签页暂存机制。存储不可用时本次内存可继续，页面明确提示无法记住进度。

会话仍为服务端内存，6 小时过期或重启会丢失；不宣称跨设备、跨服务重启恢复。本轮验证了拆信、寻声、草稿和评估阶段刷新。**2026-09-13 后续修复：有效会话内的回响页已支持只读恢复完整结局**，详见 `REPAIR-VERIFICATION-2026-09-13.md`。仍非持久档案库，服务重启/过期前请下载档案卡。

## 验证中发现并修复

1. 分类只圈第一个框会暗示答案：改为六框整体，并显示当前选句。
2. 响应式切换后参考台跑出屏幕：视口变化重新定位，增加目标必须可见断言。
3. 原有分类选择未及时暂存：每次分类后保存，可恢复已分类句子。
4. 原有评估后刷新缺少后续按钮：用服务端既有分数恢复评估、锁定已提交正文、恢复改稿/看回响入口。原流式点评未保存，明确说明，不重新编造。
5. 暂存草稿此前会被错标为“第二稿”：现按真实修订状态标记稿次。

测试脚本本身也纠正了两个问题：CDP Enter 补齐真实字符事件；桌面滚动条会使内容宽度小于视口，因此溢出判断改为“不大于”，不是强求相等。最初失败未被当作通过。

## 尚未验证及启动说明

- 本轮浏览器使用规则引擎。没有调用 DeepSeek 或付费生图；LLM mock 测试不等于真实模型验收。
- 两份旧玩法回归实际读到 10 张知乎官方公共知识卡；未配置知乎热榜/搜索鉴权，未冒称真实鉴权成功。
- 新引导脚本故意禁用知识能力，检查缺少外部服务也能通关；报告中明确是 DISABLED。
- 未做手机真机软键盘、iOS Safari、屏幕阅读器实机及全键盘全流程验收。已验收的是 Chrome 响应式视口与引导控件键盘操作。
- 没有部署、提交、发布、上传玩家内容，也没有替换用户正在运行的常驻服务。临时测试服务结束即退出。
- 本轮有服务端改动，旧服务必须重启才全部生效。可在一个终端自行启动独立预览，保持终端运行：
