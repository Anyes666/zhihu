# 知乎平台能力升级 · 回声邮局

核验日期：2026-09-13。以下结论以本仓库实现、自动化测试及真实浏览器报告为依据，不把“已配密钥”当作接口成功。

## 这次升级的产品主张

**知乎不是装饰性的热榜，而是玩家学习如何负责任地回答别人的参考台。**

原有循环为「拆信 → 寻声 → 落笔 → 回响」。现在寻声和落笔之间增加可选的「查阅 → 辨析 → 留下回执」：

1. **查阅**：主题搜索带来相似社区经历；活动知识列表提供方法参考。支持三个不同的自定义检索主题，重复查询不额外占用主题名额。
2. **辨析**：玩家选择“参考 / 对照 / 待核实”，用 8–160 字写出启发或适用边界，最多保留两条来源笔记。只允许保存本局从服务端查阅过的来源，不接受客户端伪造标题、作者或来源状态。
3. **落笔**：笔记跨阶段保留。启用模型时，点评提示词携带笔记，让模型关注资料是否被正确使用；没有模型时，原有规则点评仍然可用。
4. **回响**：封存来源、玩家反思与使用方式；增加明确标注为模拟的“资料旁观者”评论。模型启用时，结局提示词同时携带互动轨迹和笔记，但不能改变引擎确定的结局。

**不因查阅、收藏或笔记数量加分，不自动解锁来信真相，不把社区经历当作当事人的证词。** 笔记是认知过程的记录，不是“证据装备”。参考台可跳过，不消耗游戏邮票，也不因接口失败阻断主线。三个检索主题是玩法限制，不等同于三次上游调用。

| 知乎知识 | 新参考台的方法参考 | **真实 Chrome → 本地服务器 → 官方知识列表成功，返回 10 张来源卡，随后命中缓存**；不需鉴权 |

知识列表是黑客松活动接口，不承诺活动结束后持续开放。当前仅使用列表标题、短摘要、标签、work_id；作者明确显示“列表未提供作者”。按官方文档测试知识详情共享路径时曾收到 `40404 Work Not Found`，因此**不假造详情，也不声称已读取知识全文**。来源卡可打开官方列表核对 ID/标题，而不是伪造原文页面。

三封来信仍是原创虚构故事，不因知识/搜索内容而自动改写剧情。没有接 OAuth，不读取用户关注/粉丝等个人数据，也不向知乎发布任何内容。

## 缓存、频控与来源诚实性

- 热榜缓存 30 分钟；搜索、知识列表缓存 6 小时。
- 内存与磁盘两级缓存，同查询并发合并；失败冷却 60 秒，连续轮询不无限延长冷却。
- 热榜、搜索、直答每分钟本地上限分别为 4、30、10；每日本地保护阈值分别为 90、900、90。知识列表额外限制每分钟 10、每天 90，属于应用保护值，不是声称官方规定。
- 以上计数在**单个服务进程内**按北京时间自然日计算；重启会重置，多实例/同账号其他应用不共享账本。公开部署前仍需要统一网关配额与滥用保护，不能把它视为官方额度的绝对保证。
- `live` = 本次实际请求并解析成功；`cache` = API 来源缓存；`stale` = 已过期且刷新失败；`demo` = 本地演示；`unavailable` = 没有可用知识内容。
- 保存获取时间、来源能力、原始 ID、使用方式与反思；演示包不写入真实 API 缓存。
- `ZHIHU_KNOWLEDGE_ENABLED=false` 关闭知识上游请求；若已有有效缓存，仍可读缓存。严格离线演示可以同时指定新的空缓存目录。
- 上游错误正文不会直接透传给玩家；缓存读写异常通过健康接口的 `cacheWarning` 报告。
- 旧 `health.zhihu` 字段仅为兼容保留，不能用它证明请求成功。查看 `capabilities.<kind>.source/fetchedAt/stale/fallbackReason` 以及游戏来源标签。

## 模型与内容安全边界

`LLM_PROVIDER=deepseek` 明确选择 DeepSeek；知乎数据只读取 `ZHIHU_ACCESS_SECRET`。两套凭据各司其职。显式选定的模型缺密钥时回退规则引擎，不偷偷换成另一个付费供应商。未指定供应商时：兼容模型配置完整则优先使用，否则尝试知乎直答。

外部摘要和玩家笔记以低权限参考数据进入模型上下文，不再放进角色系统指令；页面输出进行 HTML 转义，来源链接仅允许 HTTPS 知乎域名。规则引擎的评分、真相、资源和结局不受笔记直接写入。

**边界不是保证**：提示词约束及长度/格式检查不能彻底保证模型事实正确或抵抗提示注入。公开上线前应继续做语义级对抗评测、输出审查、隐私处理与服务端滥用保护。本轮未使用任何用户提供的历史密钥，不声称已完成真实 DeepSeek + 真实知乎鉴权的联调。

## 三分钟现场演示建议

1. **0:00–0:35**：开《离开的人》，介绍“不是教你在评论区赢，而是理解回答会怎样影响别人”。拆信可现场做，或开场提前停在寻声阶段。
2. **0:35–1:10**：问沉默当事人“那个租房页面，您最怕的是什么？”，看到角色态度与剧情真相变化。
3. **1:10–1:50**：展开知乎参考台，展示真实 API 获取时间。选“如何从心理被动的人慢慢变为主动的人？”（以现场官方列表为准），标记“待核实”，写“这能提醒我辨别意愿，却不能据此给当事人下心理结论”。展示原真相/邮票未变化。
4. **1:50–2:35**：在回信里同时使用当事人说过的事实和谨慎的方法参考，而不是复制社区答案。寄出并看五维评分。
5. **2:35–3:00**：展示来源回执及模拟评论，解释“真实知乎内容 + 虚构叙事 + 确定性决策”的边界。若模型已单独验收，再演示生成增强；否则明确说本次为规则兜底。

评委亮点：**平台内容参与认知过程，而不是只提供皮肤；玩家保有判断责任；接口中断仍能完成一封负责任的回信。**
