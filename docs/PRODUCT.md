# 产品说明文档 · 回声邮局：未寄出的答案

知乎黑客松 2026 · 校园新锐季 · AI 游戏赛道

---

## 一、一句话

《回声邮局》把知乎最核心的那个动作——**认真回答一个陌生人的问题**——做成了一款可玩的游戏。

## 二、为什么做这个

### 我们观察到的真实问题

知乎上每天有大量这样的提问：「我该不该离开家乡」「三战值不值得」「发现同事造假要不要说」。这类问题的共同点是：

- **提问者自己没把问题问清楚。** 真正卡住他的那件事，往往被写在第七句，用「其实」开头，一笔带过。
- **回答者容易只回答表层。** 高赞回答里有一类很常见——道理都对，但没看见提问者真正在怕什么，于是被点赞，却帮不上忙。
- **最伤人的不是敷衍，是锋利的好意。** 「你妈就是在道德绑架你」这种回答经常拿高赞，也经常让提问者把回答截图转给家人，然后关系彻底坏掉。

**一个好回答需要的能力是可以被拆解和练习的**：先分清事实与情绪，再找到信息缺口，再决定说什么、怎么说、说到什么程度。这套能力在知乎社区里被反复需要，却从来没有人把它变成可以练的东西。

### 我们的答案

把「写一个好回答」变成一局游戏。玩家不是在读故事，是在**做回答者要做的每一个判断**：

| 真实的回答场景 | 游戏里的机制 |
| --- | --- |
| 读题：分清哪句是事实、哪句是情绪、哪句是他自己的预设 | 拆信阶段的六类分拣，准确率影响后续信息深度 |
| 补充信息：去搜、去问、去找当事人 | 寻声阶段的有限资源（2 次召唤 + 3 枚邮票） |
| 判断该信谁：过来人的经验？数据？反对意见？ | 四位立场各异的答主，各有强项与盲区 |
| 怎么问才问得出真话 | 提问态度识别：温和／具体／中性／引导／敌意 |
| 写回答：说结论、给依据、留余地 | 落笔阶段自由输入 + 五维评估 |
| 回答发出后真的发生了什么 | 回响阶段：人生走向 + 评论区风向 + 信息反转 |

玩完一局，玩家会具体地知道一件事：**他刚才那封回信，哪一句帮到了人，哪一句伤到了人。**

## 三、场景价值

### 对知乎社区的价值

**1. 把「如何写好回答」从说教变成体验。**
社区规范类内容（「什么是好回答」）的阅读转化一直很低，因为它是说教。游戏把它变成后果：玩家写了一封只有道理没有温度的回信，会亲眼看到提问者一年后又寄来一封几乎一样的信。这比任何规范文案都直接。

**2. 用信息差机制对抗「表层回答」惯性。**
每封信都有两层真相，只能靠提问换取。没拿到真相就给方向的玩家，会在回响阶段看到评论区有人补上他没看到的事——这正是知乎上真实发生的「高赞被反转」。这个机制让玩家学会一件事：**在回答之前，先确认自己是不是真的看懂了问题。**

**3. 还原知乎的观点生态，而不是把它简化成正确答案。**
四位答主分别对应知乎上真实存在的四种答主类型：过来人（经验派）、硬核数据答主（证据派）、反对意见答主（质疑派）、以及当事人本人。他们会互相矛盾，各有盲区，并且都会主动暴露自己的偏见（老周会说「我总觉得再拼一年没什么不好，这可能是我这种人的毛病」）。玩家要在矛盾的信息里自己做判断——这就是在知乎读一个问题下 30 个回答的真实体验。

**4. 结局卡的社区传播属性。**
每局生成一张回声档案卡：回答人格、结局走向、你写下的那句话、五维评分。它天然适合发在知乎回答里、分享到社交平台——而且它承载的是一个真实的自我认知（「我是那种只会递纸巾的人」／「我是敢下判断但容易伤人的人」），不是一个随机结果。

### 对玩家的价值

这不是一个消耗时间的游戏，是一次**具体的共情训练**。三个主题分别对应年轻人最高频的三类困境：与父母的距离、对自己的执念、在职场里的道德处境。玩完一局，玩家会更知道怎么回答身边真实的人。

## 四、知乎生态融合

所有能力都是真实落地的接口调用，不是概念。

| 知乎能力 | 在游戏里的角色 | 实现 |
| --- | --- | --- |
| **知乎热榜** | 题材联动：三封信各自匹配当日热榜中的相关话题，在门厅和信封上展示真实社区热度，可点击跳转 | `hot_list` 接口，30 分钟缓存，关键词匹配 |
| **知乎搜索** | 观点素材与评论区来源：落笔阶段展示同话题下的高赞回答片段（含作者、赞同数、原文链接），供玩家参考、引用或反驳；也作为角色对话的语料注入 Prompt | `zhihu_search` 接口，6 小时缓存，每封信一次 |
| **知乎直答** | 角色对话生成：把引擎算好的事实骨架，按角色人设与玩家提问态度改写成自然台词，流式输出 | `/v1/chat/completions`，`zhida-fast-1p5`，`stream: true` |
| **知乎直答** | 刘看山点评与结局旁白：在引擎给定的评分结论和结局大纲上生成叙事文本 | 同上 |
| **社区反馈机制** | 回响阶段模拟赞同／反对／评论：票数由五维评分非线性驱动，评论内容按结局走向抽取，低分回信会收到「这几句太绝对了」这类真实风向的评论 | 引擎计算 |
| **刘看山 IP** | 邮局夜班邮差：递信、提醒规则、指出玩家忽略的细节，从不替玩家下判断 | 视觉与语言风格贴合官方设定 |

### 降级设计

接口受限或未配置凭证时：

- 热榜 → 本地演示快照，界面标注「演示快照」
- 搜索 → 本地素材包，界面标注「演示素材包」
- 直答 → 规则引擎台词库（每个角色 × 每封信 × 五种态度都有专门台词）
- 界面右上角始终如实显示当前数据来源，不假装实时

**任意降级组合下，游戏都能完整通关。** 这一点有测试覆盖。

## 五、AI 原生性

### AI 是玩法，不是工具

| 环节 | AI 承担的角色 |
| --- | --- |
| 玩家提问 | 自然语言输入 → 态度分类 → 角色信任度变化 → 决定是否透露真相 |
| 角色回应 | 人设 + 事实骨架 + 态度 + 社区语料 → 流式生成台词 |
| 玩家回信 | 自由文本 → 五维评估（诉求、事实、温度、风险、社区适配）→ 决定结局走向 |
| 结局 | 引擎决定走向与深度 → AI 在大纲约束下生成叙事 |

没有一个按钮式剧情选项。玩家的每一次输入都是自由文本，游戏的每一次分叉都由对这段文本的理解决定。

### 事实与表达分离

这是本作最关键的工程决策：

**引擎决定「说什么事实」，模型决定「怎么说」。**

真相能否解锁、结局走哪条、评分多少，全部由确定性代码计算。模型拿到的是一段事实骨架和硬约束（「这段骨架是你唯一的事实来源，不能新增或改变任何事实、日期、数字、人物关系」）。

这样做的收益：

- **不会幻觉出不存在的剧情。** 角色不会突然编出一个新的家庭成员。
- **玩法完全可测。** 38 个测试覆盖全部分支，不受模型随机性影响。
- **降级无感。** 模型挂了就用骨架本身，玩家看到的是一句略朴素但完全正确的台词。

## 六、完成度

- 单局全流程闭环：拆信 → 寻声 → 落笔 → 回响 → 档案卡，3–5 分钟
- 三个完整主题，每个 2 层真相 × 4 种结局走向 × 3 种真相深度 = 12 条结局路径
- 五个 AI 角色，每个在每封信里都有五种态度台词 + 真相台词 + 偏见暴露
- 38 个自动化测试：引擎逻辑 19、LLM 降级链 8、服务端集成 11，全绿
- 移动端适配，无横向溢出
- 会话可刷新恢复（浏览器刷新不丢进度）
- 无依赖、无构建、无数据库，`npm start` 即可运行

## 七、局限与下一步

**当前局限，如实说明：**

- 态度识别与五维评估目前是规则实现（正则 + 关键词 + 权重）。它的好处是确定、可测、零延迟、零成本；代价是对刁钻表达的鲁棒性不如模型判分。下一步会把模型判分作为规则之上的一层校正，规则仍作为兜底。
- 真相触发依赖关键词命中。已为三封信各扩充到 23–29 个常见问法，但玩家仍可能用没覆盖的说法问到点上。下一步接入语义匹配。
- 三个主题是手工创作的。下一步做「从热榜话题生成新信件」的流水线，让题材池每天自动更新。

**如果继续做：**

1. 热榜驱动的每日新信（题材池自动扩展）
2. 玩家回信的社区化：把高分回信匿名沉淀成「回声档案馆」，后来的玩家可以读到前人怎么回答同一封信
3. 真实知乎问题的接入：在提问者授权前提下，把游戏产出的高质量回信引导到真实问题下

---

**作品定位：** 不是一个大而全的半成品，是一个小而完整的第一步。它把「什么是一个好回答」这个问题讲清楚了，并且做出了一个能玩、能通关、能分享的闭环。
