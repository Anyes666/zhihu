# 真实浏览器试玩：玩法亮点与回声邮局差距

日期：2026-09-14。目的：先筛选、实际操作，再制定升级计划。本轮没有修改游戏运行代码、发布版本或开启实时 API。

## 方法与证据口径

- 从用户提供的[知乎活动页](https://www.zhihu.com/hackathon?activity_code=zhihu_hackathon_2026_p2)进入作品详情，再打开产品链接；不是只读营销介绍。
- 本机真实 Chrome，独立临时访客上下文，通过 CDP 鼠标按下/抬起及输入事件进行操作。桌面1440×1000、部分移动模拟390×844。没有使用他人源码、绕过登录、投票、发表内容或提交真实个人资料。
- “实际观察”只指界面操作和响应；界面自称接入模型、返回200、引用知乎链接均不能证明上游真实调用。
- 回声邮局公网健康检查显示 `llm:none`、经典模式。因此本轮是实际线上规则引擎试玩，不是实时AI验收。
- 截图、逐步DOM记录、请求路径/状态及失败信息保存在 `D:/A黑客松/artifacts/competitor-review/upgrade-20260914-*`；探针及操作配置保存在 `D:/A黑客松/artifacts/upgrade-review-20260914/`。
- 筛选不是排行榜：优先选与互动叙事、表达、有限信息取舍相关的作品，不用热度证明玩法质量。

## 1. 视差 PARALLAX：把抽象主题缩成一次操作

[活动作品页](https://www.zhihu.com/hackathon/project/90035?activity_code=zhihu_hackathon_2026_p2) · [产品](https://parallax-zhihu.netlify.app/)

**实际走到：**首页 → 开始调查 → 案件零 → 点开一条虚线注脚 → 额度从1/1变成用完 → 切换第二位人物 → 点击判断入口 → 打开观察者窗口 → 手机视口。

**观察到的亮点：**
- 先用小案件教一个动作，不把整部作品的全部机制压给新人。
- 点开信息后同时出现新内容、机会耗尽提示和可继续的入口，因果关系可见。
- 切换角色后仍受已消耗额度约束，使“只能看到部分信息”成为实际取舍。
- 观察者窗口确实打开，但本轮只核对了子窗口目标，不将其中全部记录功能算作已验证。

**适配回声邮局：**增加不计分、与正式剧情隔离的练习句；让玩家完成“选句→分类→理由”一次小闭环；将线索来源、已知/未知和行动成本明确摆在眼前。不照搬案件、一次性惩罚、双窗口或反侦察设定。

**局限：**未走完正式三案、未验证最终结算；判断入口之后的叙事变化不等同完整结局。信息额度过于不可逆不适合直接用于新手教学。

证据：`upgrade-20260914-play3/parallax-footnote.json`、`upgrade-20260914-parallax-final/parallax-report.json`、`parallax-mobile-case.png`。

## 2. 观点擂台：目标、成本与回合反馈都在当前操作附近

[活动作品页](https://www.zhihu.com/hackathon/project/90032?activity_code=zhihu_hackathon_2026_p2) · [产品](https://arena-of-cards.app.workbuddy.host/)

**实际走到：**切换短视频话题 → 选择正方 → 开局 → 出牌 → 展开反驳 → 结束回合；随后独立完整走完8轮，进入观念墙。最终一次比分2:4，未点击下载、分享或知乎发布。

**观察到的亮点：**
- 当前回合、双方分数、能量与对手类型在同一操作区域可见。
- 出牌后不只更新数字，还解释本次类型关系与得失。
- 终局整理玩家实际出的牌与反驳记录，留下可回看的过程，而不是只有一个结果分数。

**适配回声邮局：**将召唤/提问成本就近说明；每次对话返回一张简短行动回执；结尾以自己的提问、证据、回信句子为主角，既有档案卡作为后续导出，不另建卡牌玩法。

**限制与不应照搬之处：**反驳明确标为mock兜底；不把这次体验称为实时AI辩论。终局部分内容跨话题、出现夸张确定性建议，故只借鉴组织方式，不能把其文本当作可靠建议。不会复制卡牌、角色、数值、克制环或原文。

证据：`upgrade-20260914-play3/cards-response.json`、`upgrade-20260914-play2/cards-mobile.png`、`upgrade-20260914-cards-final/cards-final-settled.json`。最终报告21个快照、无步骤失败、无记录到的浏览器错误。

## 3. 知乎洪荒录：选择之后必须看到变化

活动展示名“洪荒叙事”；[实际产品](https://famous-brigadeiros-22cdbd.netlify.app/)。本轮沿用项目既有调查中确认的产品地址，非凭活动名称猜测。

**实际走到：**打开游戏，等待初始选项出现，点击初始形态“先天清气化形”，阅读结果及下一步入口。

**观察到的亮点：**选择后有独立叙事反馈和属性变化清单；本次战力1500→2100，清楚显示+600。阶段路线和继续入口可见。

**适配回声邮局：**对话后将“邮票变化、信任变化、是否得到新信息、下一步”合并成短回执；角色表情仅作为同一状态的呈现，不另加一套成长数值。

**局限：**仅初始选择，不是通关。首次5秒取样尚无选项，等候后才能点到。大量世界观术语与面板并不适合照搬到回声邮局的新手首屏；未验证其真实知乎/AI上游能力。

证据：`upgrade-20260914-play2/honghuang-home.json`、`honghuang-choice1.json`及同名截图。

## 5. 回声邮局：真实走完第一封信后的具体发现

[公开游戏](https://agrdkgglknfj.sealosbja.site/)

**实际路径：**首次引导 → 底部介绍 → 第一封信 → 九句分类（故意错一处）→ 封存 → 召唤南的母亲 → 编辑示例提问并发送 → 获取一层真相 → 跳过可选参考 → 自写回信 → 评估 → 结局 → 完成引导 → 平行试写另一版回信。

### 已经存在、应加强而不是重新开发的优势
- 原创信件、有限资源、多角色视角、线索板、四步进度、开口提示、草稿暂存、来源标签、行为时间线、档案卡和平行试写都已经存在。
- 实测8/9分类正确获得1枚额外邮票；召唤消耗一次机会；编辑提示语不扣邮票，发送后扣1枚，获得一层新信息。
- 真正替换另一版回信后，平行试写显示温度+8、结局仍为同类；页面诚实说明走向没有改变。这是现有能力，不应包装成拟新增功能。

### 优先问题

| 编号 | 实测现象 | 结论与建议 |
|---|---|---|
| E1 | 手机介绍先整页跳到底部，正文内部可滚动，下方还有一张解释介绍的引导卡 | 布局未互相遮挡，但阅读层级重复、完成介绍之前没有学到一次具体动作。保留底部完整版，入口简化并加入短练习。 |
| E2 | 故意把第一句事实放入情绪后，计数变1/9，引导继续整理；九句封存才出现纠正 | 正式局延迟揭晓可以保留，但新人缺少低风险练习。用独立例句教学，不预泄漏正式句子的答案。 |
| E3 | 手机点击选句后，页面滚到六个分类框；原句离开屏幕，只有提示卡中截断的引用 | 增加“当前选中完整句子”与分类按钮的同屏区域；不扩大覆盖层、不持续抢滚动。 |
| E4 | 顶栏资源缩成“召/邮/真/改”，操作规则分散在介绍、卡片、提示和聊天区 | 改为可读名称及就近成本说明；提供本次动作回执，而不是只依赖顶栏数字和短toast。 |
| E5 | 只解锁1/2真相，结果却显示全部，同时列出还有1层没看到 | 实际口径冲突。代码中depth综合已解锁和回信提及程度，标签却被写成真相覆盖率；优先分开“已确认线索”与“回信依据覆盖”，不要未经确认改变评分阈值。 |
| E6 | 平行试写替换文本后只看到五维变化/同类结局，缺少为什么变的解释 | 复用现有对照流程，突出改变了哪些表达、哪些结果没变；解释来自引擎证据，不能让模型编造因果。 |
| E7 | 首屏显示预算尚未开放，体验为规则引擎 | 普通玩家主提示改为模式及可玩范围，预算细节下沉。不得隐藏非实时事实或自动开启付费调用。 |

E5代码依据：`D:/A黑客松/lib/engine.mjs` 的 `truthScore`/`depth` 计算和 `DEPTH_LABEL`；本局回信提到了未解锁线索相关内容，导致综合深度达到full，而missed仍按实际解锁数计算。是不同概念共用一个标签，不是已证明的隐藏真相泄漏。

证据：`upgrade-20260914-echo/echo-select-first.png`、`echo-wrong-first.json`；`upgrade-20260914-echo-complete/echo-seal.json`、`echo-answer.json`、`echo-complete.json`；`upgrade-20260914-echo-parallel-replace/echo-parallel-result.json`。

## 限制、失败与纠正

- 网页检索工具对活动页没有返回可用正文，改用本机Chrome，实际进入活动页、产品页和游戏，不据空结果作结论。
- 页面提取打印遇到一次Windows GBK编码错误，改为UTF-8后读取已保存证据，无内容丢失。
- 第一次卡牌八轮探针等待不足，末次快照尚在第8轮，未据此称通关；第二次增加等待后实际出现观念墙。
- 第一次平行试写输入探针追加了文本而非替换，不能当作独立改稿；修正为Ctrl+A后输入，重新完整走一轮，最终对比证据仅采用replace目录。
- 活动详情页记录到 `net::ERR_FAILED`、`net::ERR_ABORTED`；回声邮局完整流程记录到若干 `net::ERR_ABORTED`。本轮未对这些请求取消归因，因此不能报告全程零网络错误；所述关键操作均有实际成功界面证据。
- 本轮未进行正式真人可用性招募、眼动/留存研究或真实移动设备软键盘测试，不能声称已经证明新手转化提升。
- 截图只用于本地分析，不作为新游戏美术，不提交玩家资料或竞争产品素材到AI服务。
