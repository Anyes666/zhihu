# API 预算保护与验证

日期：2026-09-13。范围：网页游戏运行时的知乎公共检索/知识和模型生成；不配置 OAuth，不触碰用户 `.env`。

## 当前默认行为

- `API_LIVE_ENABLED` 不为 `true`，或某能力缺少有效的每日/累计预算：阻止该能力的新上游请求。
- 已有缓存先读；无缓存使用已有演示或明确不可用。角色、点评、结局仍可走完整规则流程。
- 不自动猜测官方余额或人民币预算；保留已有真实凭据，但有凭据不等于批准消费。
- 保护是新后端的能力。旧服务进程不自动更新，必须重启到新代码；本次不终止用户常驻服务。

## 调用保护

1. 读取公共缓存，合并同查询并发；命中缓存不预留新额度。
2. SQLite `BEGIN IMMEDIATE` 同时校验全站每日/累计调用数、模型预留单位、玩家/IP每日与分钟限制、并发租约。
3. 事务提交预留后才发送上游请求。HTTP失败、超时、断流均保留调用数与预留单位；不做乐观退款。
4. 响应读取结束/取消释放并发租约，不退已用额度。进程崩溃租约10分钟后释放，但累计费用预留不清零。
5. 服务端对同一游戏局的变更串行处理；在途重复操作返回409。完成后的相同上一条提问、当前点评、正式结局重放已有结果，不再次生成。
6. 点评流未完成时前端明确禁用改稿/看回响；完成后再启用。避免和服务端互斥机制冲突。

### 每项能力独立预算

`API_LLM_*`、`API_HOT_*`、`API_SEARCH_*`、`API_KNOWLEDGE_*` 分别设 `DAILY_CALLS` 与 `TOTAL_CALLS`，默认0。LLM还必须设置 `DAILY_UNITS` 和 `TOTAL_UNITS`。每日边界为北京时间零点；累计边界是当前账本的完整生命周期。

所有配置项见 `.env.example`；配置仅在重启后载入。不要把测试里的放宽上限复制为生产批准值。

`API_LLM_MAX_OUTPUT_TOKENS` 默认800，传入官方 `max_tokens`；`API_LLM_MAX_INPUT_BYTES` 默认24000。模型不遵守输出限制时，本地另设输出字节和单消息缓冲上限并取消流，但不能声称取消后供应商一定停止计费。生成最多等待30秒。

模型单位计算：`UTF-8字节长度(JSON.stringify(messages)) + max_tokens + 1024`。这是保守预留估计，不是官方准确分词或人民币账单。没有拿到最终usage也不退预留。**全站调用数是应用实际放行数的硬上限；不能把估算单位说成精确账单硬上限。** 同一个密钥在其他客户端的使用不受本账本控制。

直答：官方已下载材料中没有找到可核验的最大输出参数，因此生成入口显式抛出 `BUDGET_PROVIDER` 并规则降级。没有让该备用路径绕过新保护，也没有宣称其预算联调通过。当前用户指定的 DeepSeek `deepseek-flash` 保持不变。

## 身份与隐私

- 匿名玩家使用签名的 `HttpOnly; SameSite=Lax` Cookie；HTTPS部署设置 `API_SECURE_COOKIE=true`。
- 账本仅保存HMAC后的玩家/IP标识、类型、时间、预留单位、计数，不保存原始IP、API Key、对话或回信。
- 默认忽略 `X-Forwarded-For`。仅在确认直接上游代理可靠追加/重写来源头后配置 `API_TRUSTED_PROXY_IPS`。
- 清Cookie、换IP仍可能规避匿名玩家识别，所以最终依靠不可由玩家修改的全站累计预算兜底。校园共享IP可能提前进入经典模式，可由运营方在全站预算之内调整IP阈值。
- 没有公开管理员调额接口。查看计数使用本机 `node --env-file=.env scripts/budget-status.mjs`。它输出本应用预留账本，不冒充供应商余额。

## 部署要求与残余风险

- Node 24+，使用内置 `node:sqlite`，未安装第三方数据库依赖；Docker基础镜像已改为Node24。
- `data/budget/` 必须挂载到持久卷并限制访问。数据库、WAL、SHM和签名材料排除出Git/Docker构建上下文。
- 单机常驻进程可共用同一SQLite账本。多容器/多机器若各自用独立数据库，预算会被重复分配：禁止据此横向扩容；扩容前迁移到支持原子扣额的共享数据库。
- 不要删除、替换或清空账本；不要用临时目录或`:memory:`运行正式服务。持久卷丢失或手动删除会丢失累计记录。
- 数据库损坏/不可写时停止新实时请求，不自动删除重建。规则模式仍可用。
- 本次没有设置真实费用额度、没有部署、没有构建Docker镜像、没有进行付费API压测。已有旧服务的运行参数没有修改。
