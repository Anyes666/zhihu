## 知乎登录与个性化参考

已接入可选 OAuth：同源授权跳转、`/auth/callback`、服务端会话、昵称头像、主动生成个性化引导及退出。配置完整后才开放官方授权；未配置、拒绝或校验失败时保持公共玩法，不伪造登录身份，也不切换搜索/热榜额度。

个性化只使用用户主动授权后最小读取的主题摘要，通过确定性规则推荐来信，不将个人资料发给模型。Token 仅保存在单副本进程内存；回调必须返回匹配的 state，用户必须亲自确认授权。实现测试不等于真实授权验收。

配置、请求限额及验证边界见 [知乎 OAuth 接入说明](docs/ZHIHU-OAUTH.md)。页面底部保留可折叠游戏介绍；首次引导用摘要说明目标与介绍位置，再进入独立的两句分类练习，支持跳过或重玩。

## API 额度保护（2026-09-13）

**需要 Node 24+。新版本默认不发起任何新的实时 API 请求**，即使已有 DeepSeek/知乎凭据；已有缓存、演示资料与规则主线仍可使用。需要在服务端明确配置 `.env.example` 的预算字段、开启 `API_LIVE_ENABLED` 并重启后，才能在限定预算内放行。若运营者明确接受模型供应商侧的费用与限流责任，也可额外开启 `API_LLM_UNLIMITED=true`，仅取消 LLM 的应用侧每日/累计调用与预留单位上限；知乎接口预算不受影响。仓库仅包含安全默认模板，不包含本机 `.env`、真实凭据或预算账本；每个部署须由维护者单独批准用量。

- SQLite 事务在调用前预留每日/累计额度，跨进程、跨重启不清零；失败或超时不退款。
- 匿名玩家与 IP 限额跨局累计，签名 Cookie 与全站预算一起约束新开局；这不是强身份认证。
- 模型输入/输出上限、并发限制、重复提问/点评/定稿重放；额度耗尽回退经典模式。
- 预算单位是保守预留估计，**不是官方 Token 余额或人民币账单上限**。
- 直答生成路径暂不放行：尚未核实它的最大输出参数，不能绕过保护。当前 DeepSeek 路径不受此限制。
- `API_LLM_UNLIMITED=true` 不是供应商余额或账单上限：仍保留总开关、分钟频率、并发、单次输入/输出长度、超时和账本记账；关闭后也不会清除历史记录。

本地查看账本（只读用量输出，不调用 API）：`node --env-file=.env scripts/budget-status.mjs`。

详细配置、部署边界和验证记录见 [API预算保护与验证](docs/API-BUDGET-PROTECTION-2026-09-13.md)。

## 快速开始

```bash
npm start
```

打开 http://127.0.0.1:3000 即可。无第三方运行依赖、无前端构建；预算账本使用 Node 内置 SQLite，运行时按需创建。

不配任何密钥也能走完整流程：热榜/搜索使用本地演示包，角色对话由规则引擎保证输出；新知乎参考台在批准知识接口预算后可独立读取官方活动知识列表，并明确区分 API 获取、缓存与演示。

接入知乎热榜/搜索（PowerShell，先在本机安全设置环境变量）：

```powershell
# 在本机配置 ZHIHU_ACCESS_SECRET 后启动，不要把真实密钥写入本文。
npm start
```

Access Secret 在 https://developer.zhihu.com/profile 申请。配置仅表示准备调用，是否成功须看实际来源标签。`LLM_PROVIDER=deepseek` 与 `LLM_API_KEY` 单独控制 DeepSeek；不会被知乎数据凭据抢占。`npm start` 不自动加载 `.env`；可使用进程环境变量，或 Node 24+ 执行 `node --env-file=.env server.mjs`。详见 `.env.example`。

## 玩法

四个阶段，一局走完：

1. **拆信** — 把来信的每一句话分进事实、情绪、诉求、偏见、逃避、关键线索六类。分得准会多拿一枚邮票，并解锁通往隐藏真相的方向提示。
2. **寻声** — 用 2 次召唤、3 枚邮票，向四位立场各异的答主提问。提问的态度会被识别（温和／具体／中性／引导／敌意），直接决定对方说多少、说不说真话，以及会不会转身离开。
3. **落笔** — 自由输入，没有选项按钮。系统从诉求回应度、事实准确度、情感温度、风险规避度、社区适配性五个维度评估这封回信。
4. **回响** — 不判对错。模拟回信寄出一个月后写信人的真实走向、知乎评论区的风向、以及可能出现的信息反转，最后生成可分享的回声档案卡。

三封首发来信：《离开的人》《三战》《同事的秘密》。每封两层隐藏真相、四种结局走向 × 三种真相深度，共 12 条结局路径。


## 设计原则

**AI 是玩法本身，不是素材工具。** 玩家的自然语言提问被识别为五种态度，驱动角色的信任度与信息披露；玩家的自由回信被五维评估，直接决定结局走向。没有一条剧情分支是预先写死的按钮选择。

**事实由代码决定，表达由模型负责。** 真相能否解锁、结局走哪条路、评分多少分，全部由 `lib/engine.mjs` 的确定性规则计算。语言模型只负责把引擎给出的事实骨架说得像那个角色会说的话。模型超时、报错、或角色输出格式不合格（带 markdown、过短），立刻回退到规则台词，玩法不中断。提示词和格式校验并不能保证模型语义绝对正确；评分和真相仍以引擎为准。

**降级是功能，不是补丁。** 知乎接口、语言模型各有独立降级路径，任意组合下游戏都能完整通关。当前数据来源在界面上如实标注，不假装实时。
